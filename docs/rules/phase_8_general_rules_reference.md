# Phase 8 武将规则版本参考

本文件锁定 Phase 8 第一批 11 名武将所采用的**唯一规则版本**，供实现、测试与后续扩展对照。
项目为「标准版 + 军争篇」的本地多人自由混战，不含身份模式、国战、双将、界限突破与 OL 重制。

---

## 一、版本选择原则

1. **统一采用经典标准版技能**（2009 标准版 / 2011 标准版一版技能），不做任何混搭。
2. 不采用国战版本（2 体力、珠联璧合、主副将体力等）。
3. 不采用界限突破、OL 重制、SP 版本。
4. 不做主公技（激将 / 护驾 / 救援 / 黄天 / 血裔），它们与身份模式强相关。
5. 技能描述里凡涉及「身份」「阵营」「队友」的部分，在本项目的自由混战语义下统一简化为「任意其他角色」。
6. 凡经典版本包含「弃两张手牌或受到 1 点伤害」这类二选一结算的，本项目第一版统一取**其中一种固定结算**并在下表注明，以避免引入未验证的交互。

## 三、技能规则说明

### 1. 张飞 · 咆哮（锁定技）

> 出牌阶段，你使用【杀】无次数限制。

- 本阶段实现：`SLASH_QUOTA` modifier（Phase 7 已实现，本阶段补齐测试）。
- 采用版本：标准版。

### 2. 黄月英 · 集智 / 奇才

> **集智**：当你使用一张锦囊牌时，你可以摸一张牌。
>
> **奇才**（锁定技）：你使用锦囊牌无距离限制。

- 集智实现：`CARD_USED` 触发 → 摸一张（Phase 7 已实现）。
- 奇才实现：新增 `TRICK_RANGE_IGNORE` modifier，让锦囊的 `distance_limit` 检查被跳过。
- 采用版本：标准版（奇才为锁定技的版本）。

### 3. 夏侯惇 · 刚烈

> 当你受到伤害后，你可以进行一次判定：若结果不为红桃，则伤害来源受到 1 点伤害。

- 本阶段实现：`DAMAGE_SETTLED` 触发 → 判定 → 非红桃则反伤 1 点（Phase 7 已实现）。
- **简化说明**：经典版本为「伤害来源弃置两张手牌，否则受到 1 点伤害」。本项目第一版直接取「受到 1 点伤害」分支，不做弃牌二选一。
- 采用版本：标准版（简化结算）。

### 4. 曹操 · 奸雄

> 当你受到伤害后，你可以获得造成此伤害的牌。

- 本阶段实现：`DAMAGE_SETTLED` 触发 → 从处理区/弃牌堆取回**真实的实体牌**（`damage.card` 与其 `source_cards`），不按牌名重新生成。
- 若伤害来自技能转化的虚拟牌（如武圣把【桃】当【杀】），取得的是**原始实体牌**。
- 采用版本：标准版。

### 5. 司马懿 · 反馈 / 鬼才

> **反馈**：当你受到伤害后，你可以获得伤害来源的一张牌。
>
> **鬼才**：在任意角色的判定牌生效前，你可以打出一张手牌代替之。

- 反馈实现：`DAMAGE_SETTLED` 触发 → 从来源手牌（无手牌则装备区）随机取一张。
- 鬼才实现：**Judge Replacement** 通用机制（本阶段新增基础设施）。
- 采用版本：标准版。

### 6. 郭嘉 · 天妒 / 遗计

> **天妒**：当你的判定牌生效后，你可以获得此牌。
>
> **遗计**：当你受到 1 点伤害后，你可以摸两张牌。

- 天妒实现：`JUDGE_FINISHED` 触发 → 取得**最终生效的判定牌**（在鬼才替换之后）。
- 遗计实现：`DAMAGE_SETTLED` 触发 → 按实际伤害点数摸 2×N 张。
- **简化说明**：经典遗计可以把摸到的牌分配给其他角色。本项目第一版取「自己摸两张」，不做分配 Pending。
- 采用版本：标准版（简化分配）。

### 7. 张辽 · 突袭

> 摸牌阶段，你可以放弃摸牌，改为获得至多两名其他角色各一张手牌。

- 实现口径：`PhaseReplacement(phase=DRAW)` 阶段钩子 → 询问是否发动 → `TuxiFlow`
  用通用的「选择目标」请求让玩家挑 1～2 名有手牌的其他存活角色 → 各随机获得一张手牌
  （取该角色的第一张手牌）→ 本回合摸牌阶段整体跳过。
- 候选目标在进入选择前就过滤掉自己、阵亡角色与无手牌角色；引擎在取牌前再复核一次。
- 取消选择 = 不发动突袭，摸牌阶段照常结算（不会出现"既没摸牌也没拿到牌"）。
- 限制为每回合一次（`SkillState` + `ResetScope.TURN`）。
- 采用版本：标准版（本项目取"放弃摸牌"口径，不做"少摸任意数量"的变体）。

### 8. 关羽 · 武圣

> 你可以将一张红色牌当【杀】使用或打出。

- 本阶段实现：**CardConversion** 通用机制（本阶段新增基础设施）。
- 覆盖场景：出牌阶段主动使用、响应【杀】/南蛮入侵需求时打出。
- 采用版本：标准版。

### 9. 赵云 · 龙胆

> 你可以将【杀】当【闪】、【闪】当【杀】使用或打出。

- 本阶段实现：CardConversion（双向）。
- 覆盖场景：响应【杀】/万箭齐发时杀当闪；出牌阶段或响应南蛮/决斗时闪当杀。
- 采用版本：标准版。

### 10. 周瑜 · 英姿 / 反间

> **英姿**（锁定技）：摸牌阶段，你额外摸一张牌。
>
> **反间**：出牌阶段限一次，你可以令一名其他角色选择一种花色，然后你展示一张手牌并交给该角色；若该角色没有弃置一张与此牌花色相同的手牌，则受到 1 点伤害。

- 英姿实现：`DRAW_COUNT` modifier（+1）。
- 反间实现：**主动技能**（出牌阶段限一次）+ 目标选择 + 花色选择（ChooseOption）+ 展示手牌（SelectCards）→ 目标弃牌或受伤。
- 采用版本：标准版。

### 11. 孙尚香 · 结姻 / 枭姬

> **结姻**：出牌阶段限一次，你可以弃置两张手牌并选择一名已受伤的男性角色，你与其各回复 1 点体力。
>
> **枭姬**：当你失去装备区里的一张牌后，你可以摸两张牌。

- 结姻实现：主动技能 + 性别与受伤状态校验 + 弃两张手牌的 SelectCards + `RecoverHpAtom`。
- 枭姬实现：`EQUIPMENT_LOST` 触发 → 摸两张（替换装备、被拆、被顺都会触发）。
- 采用版本：标准版。

## 四、本阶段明确不实现

- 主公技、身份相关技能（激将 / 护驾 / 救援 / 黄天 / 血裔）
- 界限突破 / OL 重制 / SP / 神将技能
- 国战规则（双将、暗置明置、珠联璧合、势力确认、野心家）
- 任何需要阵营判定的技能分支

## 五、实现口径速查

| 机制 | 对应武将 | 通用扩展点 |
|---|---|---|
| 锁定技 modifier | 咆哮、英姿、奇才 | `ModifierSpec` |
| 摸牌触发 | 集智 | `CARD_USED` + `DrawCardsAtom` |
| 伤害后触发 | 刚烈、遗计、反馈、奸雄 | `DAMAGE_SETTLED` |
| 判定后触发 | 天妒 | `JUDGE_FINISHED` |
| 判定替换 | 鬼才 | **Judge Replacement** |
| 卡牌转化 | 武圣、龙胆 | **CardConversion / VirtualCard** |
| 阶段替换 | 突袭 | `PhaseReplacement.flow` + `SELECT_TARGETS` |
| 主动技能 | 反间、结姻 | `SkillDef.activate` + Pending |
| 装备触发 | 枭姬 | `EQUIPMENT_LOST`（由 `UnequipAtom` 统一发出） |
