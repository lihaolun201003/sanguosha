## 需修：同一张牌重复提交为主动技费用会先扣牌再抛异常

- 位置：`src/game/skills/activation.py:190-244`。`payable` 允许同一实体牌出现两次。支付前的 `cost_placement()` 两次都能找到它，候选校验也两次通过；支付循环第一次成功，第二次 `MoveCardAtom` 找不到来源牌并抛 `ValueError`。因此“先全部定位、再全部支付”仍未保证失败时不改状态。
- 真实引擎复现：孙权在出牌阶段只有一张黑桃【杀】。提交 `ActivateSkillAction(sunquan, "zhiheng", cards=[sha, sha])`；`engine.submit()` 抛出 `ValueError: card is no longer in the expected source zone`。提交后该【杀】已从手牌移入弃牌堆，孙权未摸牌，`zhiheng.used == 0`。玩家损失一张牌，却仍可再次发动。此路径也涉及【极略·制衡】及其他允许多张费用牌的技能。
- 建议在任何移动前按实体身份检查费用牌不重复，并验证所有费用牌的当前区域和候选资格；无效提交应返回规则错误，不抛未捕获异常，不移动牌、不扣标记、不写次数。对手牌重复、装备牌重复、手牌与装备混选都做一次正反验收。不要只靠界面去重：远程提交与脚本仍会到达引擎入口。
