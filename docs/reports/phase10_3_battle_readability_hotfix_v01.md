# Phase 10.3 战场可读性与动画节奏 Hotfix 报告

- 日期：2026-09-20
- 目标：**不看日志也能看懂"谁用了什么牌 → 指向谁 → 谁响应 → 最后发生什么"**
- 测试：开工基线 **817** → 收工 **858 全绿**（新增 41），compileall PASS
- 未改动：武将技能、身份规则、距离规则、AI、牌堆规则、卡牌效果

## 1. 原动画可读性问题

| 现象 | 根因 |
| --- | --- |
| 出牌时箭头和牌同时出现，来不及看牌 | 箭头在 `CARD_USED` 时立即创建，没有"亮牌"停顿 |
| 箭头被面板/卡牌挡住 | 箭头画在真人区域之后，但**低于** prompt、按钮、战报、技能区 |
| 箭头消失太快 | 生命周期是固定时长（1.2s），不区分是否还需要响应 |
| 最慢档仍然太快 | 表现层没有"最慢档"，引擎默认速度也是 1.0 |
| 开局 4 张牌直接出现 | 没有发牌表现 |
| AI 装备 Tooltip 压住面板 | Tooltip 位置写死"鼠标右下"，不考虑避让 |
| "发动技能"是泛化占位按钮 | 技能区只有一个大按钮，没有显示真实技能名 |

## 2. 新的 Presentation / Timing 方案

### 语义化时间表

`FXTiming` 改成按**语义阶段**命名（不再按控件），只在这一处调：

| 阶段 | 用途 | 基准值 | 默认档(slow) | 最慢档 |
| --- | --- | --- | --- | --- |
| `card_reveal` | 中央亮牌 | 0.55 | 0.72 | 0.96 |
| `card_reveal_hold` | 亮牌后停顿（箭头还没出现） | 0.45 | 0.59 | 0.79 |
| `arrow_enter` | 箭头淡入 | 0.30 | 0.39 | 0.53 |
| `arrow_hold` | 箭头稳定停留 | 0.90 | 1.17 | 1.58 |
| `response_prepare` | 进入响应前停顿 | 0.50 | 0.65 | 0.88 |
| `response_card_show` | 响应牌展示 | 0.85 | 1.11 | 1.49 |
| `damage_show` / `heal_show` | 伤害 / 治疗 | 0.85 | 1.11 | 1.49 |
| `judge_reveal` / `judge_hold` / `judge_swap` | 判定 / 结果 / 改判 | 0.70/0.85/0.50 | — | — |
| `initial_deal_card` | 开局每张牌 | 0.28 | 0.36 | 0.49 |
| `between_actions` | 普通动作间隔 | 0.35 | 0.46 | 0.61 |
| `banner_hold` | 动作横幅停留 | 1.30 | 1.69 | 2.28 |

旧的属性名（`card_play` / `target_arrow` / `target_step` / `judge_display` …）保留为派生值，既有调用点与测试不受影响。

### 档位

```
very_slow 1.75   ← 新增：最慢档，一帧不落地看懂一局
slow      1.30   ← 默认
normal    1.00
fast      0.70
```

引擎节奏（`Game.SPEED_STEPS`）保持 `(0.4, 0.55, 0.75, 1.0, 1.5, 2.0)`，默认 `0.75`。

**慢速不是降帧**：游戏帧率不变，只是**事件之间留出表现时间**；窗口在动画期间照常刷新，没有任何 `time.sleep`。

## 3. 箭头生命周期（绑定语义阶段）

```
CARD_USED  → 创建箭头（hold=True, key=card），并带 base_delay = card_reveal_hold
             ↓
        （亮牌停顿：箭头已存在但 alpha=0，玩家只看得到牌）
             ↓
        arrow_enter 淡入 → 稳定停留（alpha=255，不自动消失）
             ↓
PENDING_RESOLVED   → 该牌相关箭头 release() → 开始淡出
CARD_USE_FINISHED → 兜底释放：无论有没有响应，用牌结束必释放
arrow_max_hold    → 异常兜底上限（默认 9s × 档位），避免箭头永远挂着
```

- **需要响应的牌**：箭头一直留到响应结束（`PENDING_RESOLVED`）——满足"目标进入响应之前箭头不能消失"。
- **无需响应的牌**：留到 `CARD_USE_FINISHED`。
- 释放后按剩余生命淡出，视觉上仍然是"先消失、再继续伤害"。

绘制层级（Renderer draw 顺序末尾）：

```
座位 → 中央牌 → 真人区 → Prompt → 按钮 → 浮字 → 战报 → 技能区
      ↓
【FX overlay】 发牌飞行牌 → 指向箭头 → 动作横幅
      ↓
悬停提示（Tooltip）/ 模态
```

箭头与横幅是独立图层，**高于所有常规面板**；只有 Tooltip 与模态能盖住它们。

## 4. 开局发牌动画

- 引擎在发完牌后登记 `deal_presentation = (真人和他的手牌)` —— **只登记，不发牌**。
- Renderer 首次绘制时把它转成 `DealFlight` 队列：每张牌从**牌堆位置**飞向**手牌区**，按真实顺序逐张落位（`delay = index × initial_deal_card`）。
- 飞行中的牌用**牌背**绘制；同时 `draw_hand` 跳过这些牌（`skip_card_ids`），避免"同一张牌出现两次"。
- 落位后手牌自然出现，**实体牌数量从头到尾不变**。

真实发牌顺序是"每名玩家连续 4 张"（`for player: player.draw_cards(deck, 4)`），动画按传入的 cards 顺序播放，不重排、不抽牌。

## 5. 技能 UI（数据驱动）

**移除了泛化的「发动技能」占位按钮**，改为按玩家**当前绑定的技能**逐个列出真实技能名。

数据来源：`game.skills.skill_ids_of(player)`（武将技能 + 装备技能 + 额外绑定），说明内容来自 `SkillDef.name / description / kind`。

| 技能类型 | 表现 | 点击行为 |
| --- | --- | --- |
| **主动技**（反间 / 制衡 / 苦肉…） | 可发动时金色高亮 + 发光；不可发动时变暗 | 发动（进入输入流程） |
| **视为技**（武圣 / 龙胆 / 倾国 / 急救…） | 同上（有合法素材才算可发动） | 发动（进入"先点技能再选牌"） |
| **锁定技**（咆哮 / 英姿 / 空城…） | 深色标签，不伪装成发动按钮 | 展开说明 |
| **触发技**（集智 / 奸雄 / 遗计…） | 同上 | 展开说明 |

说明面板显示「技能名 + 类型 + 描述（+ 当前无法发动的原因）」，内容全部来自 `SkillDef`，**没有第二套技能说明文本**。点击锁定/触发技只展开说明，不改变任何规则状态。

每次 sync 都重新读取引擎绑定表，因此 25 名武将（含第二批）与装备技能都自动适配，加武将不需要改 UI。

## 6. Tooltip Placement

新增通用 `widgets.place_tooltip(anchor, size, viewport, avoid=…, gap, margin)`：

- 候选顺序：右 → 左 → 下 → 上 → 右下 → 左下 → 右上 → 左上；
- 取第一个"完整落在视口内、且与 `avoid` 完全不相交"的位置；
- 全部相交时取**相交面积最小**的那个（保证至少不越界）；
- **`anchor` 自己也会加入 avoid**，所以提示框永远不会压住被查看的对象。

卡牌 Tooltip 与纯文本 Tooltip 都改用它，避开区域包括：全部座位面板、真人状态条、手牌区、Prompt、主/次按钮。这直接修掉了"查看 AI 装备时 Tooltip 压住 SeatPanel"的问题。

## 7. 牌堆 / 弃牌堆弱化

- 尺寸从 `100×140` 缩到 `58×82`，位置挪到中央区域左右两端，把中间让给结算卡与箭头。
- 文案改为一行小字：`牌堆 30` / `弃牌 1`（弃牌堆仍显示顶牌缩略）。
- **悬停**时在该图标上方弹出放大预览（牌背 / 弃牌顶牌），平时不占地方。

新增测试重点覆盖用户要求的验收点：

- `very_slow` 档确实最慢，且关键阶段（亮牌 ≥0.8s / 响应 ≥0.8s / 伤害 ≥0.7s）达到"跟得上"的量级；
- 箭头创建时 **alpha=0**（亮牌阶段），停顿结束后 **alpha=255**；
- 响应未结束时箭头不消失（推进 2 秒仍在且不淡出），释放后才消失；
- 每张开局牌**恰好一次**表现，动画不改变手牌数量，第二次绘制不重复播放；
- 25 名武将都能在技能区列出自己的技能（主公技按规则不绑定）；锁定技/触发技不进"可发动"集合；
- Tooltip 在四角与中央都不越界，且不压住被查看的座位。

## 11. 非阻断问题

1. **发牌动画只播放真人的**：AI 的 4 张牌直接出现（按任务书"至少真人必须看得出来"）。若要全员播放，需要按座次排队，整体开局会明显变长。
2. **技能说明的展开状态没有自动重置**：点开的说明会保留到再次点击或切换武将；没有加"几秒后自动收起"。
3. **多技能武将的技能按钮是竖排**（最多 3 个，每个 44px），超长技能名会省略号截断；目前 25 名武将最多 2 个技能，未遇到拥挤。
4. **动作横幅与回合横幅共用中央区域**：两者同时出现时上下紧邻（横幅在上、回合提示在下），已错开但间距不大。
5. **决斗的多次响应**：箭头会在第一次响应结束后释放（后续每次要牌仍有 Pending 高亮与提示条）；如果希望整场决斗只画一根箭头，需要把释放条件从 `PENDING_RESOLVED` 改成 `CARD_USE_FINISHED`。
6. 前几阶段记录的问题（骅骝缺素材、普通牌背缺失、观星无重排 UI、无双未覆盖决斗、iCCP 提示）本次按要求未处理。
