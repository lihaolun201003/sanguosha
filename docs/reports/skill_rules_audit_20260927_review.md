# 技能修复复核：仍需处理的两项（2026-09-27）

复核对象：`skill_rules_audit_20260927_fixes.md` 所述当前工作区实现。重新运行 `.cache/phase27/probe_*.py`，16 个脚本均退出成功，共 188/188 条断言通过。以下两项是现有探针没有覆盖、但可从当前代码和真实 `Game` 局面复现的规则缺口。本次复核没有修改技能实现。

## 1. 【黄天】只在出牌阶段开始时能交牌

- 位置：`src/game/skills/expansions/wind.py:701-734`。
- 现在只监听 `PHASE_START(PLAY)`，如果群势力角色进入出牌阶段时没有【闪】/【闪电】，后来在该阶段获得其中一张牌，就没有再发动的入口。即使进阶段时有牌但选择放弃，之后同阶段也没有机会交牌。
- 官方选用版本写的是“其他群势力角色的出牌阶段限一次，该角色可以将一张【闪】或【闪电】交给你”，限定的是整个出牌阶段和使用次数，不是阶段开始时。参考：<https://www.sanguosha.com/news/20151120_9208_0910>。
- 真实对局探针：四人身份局，张角为主公、吕布为群将。吕布以三张【杀】进入自己的出牌阶段，`game.phase == "play"` 且没有【黄天】请求；这时给他一张【闪】并推进引擎，仍无【黄天】请求。现有 `probe_huangtian.py` 只验证阶段开始已有【闪】的情形，因此 11/11 不能覆盖此问题。
- 修复验收：群势力角色在自己的出牌阶段任意合法时点都能主动选择交一张符合条件的牌给张角；每名角色每个出牌阶段最多成功交一次；阶段开始放弃后，本阶段稍后仍可交；阶段中获得牌后也可交。保留交牌者的确认和选牌权。

## 2. 孙权【制衡】与【极略·制衡】不能弃装备区的牌

- 位置：`src/game/skills/standard/wu2.py:41-60,435-445`、`src/game/skills/expansions/god.py:323-357,1503-1516`；共同的费用入口 `src/game/skills/activation.py:45-52,97-125`。
- 两个 `_can_*` 都要求有手牌，`variable_cost` 的候选与支付源也都硬编码为 `player.hand`。当前技能描述均为“弃置任意张牌”，没有限定手牌。官方孙权经典版也写“弃置任意张牌，然后摸等量张牌”：<https://www.sanguosha.com/hero/8>。
- 真实对局探针：孙权处于出牌阶段，手牌 0 张、装备区有【诸葛连弩】；`game.skills.can_activate(player, "zhiheng")` 返回 `False, "没有可以弃置的手牌"`。即使有手牌，装备区的牌也不能作为费用提交。极略版复用相同的 `variable_cost` 入口，同样受限。
- 修复验收：两种制衡都能从手牌、装备区混合选择任意正数张合法牌；只有装备牌时也能发动；每张装备按卸装原子离开，触发应有的失去装备事件；摸牌数等于实际弃牌数；取消或费用校验失败时牌与“忍”标记均不变。通用费用入口的扩展需保留其他技能原有的手牌限制。
