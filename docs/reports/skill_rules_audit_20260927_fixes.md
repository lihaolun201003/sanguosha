# 武将技能规则审查修复报告（2026-09-27）

本报告对应 `docs/reports/skill_rules_audit_20260927.md` 清单的**逐条修复**。
每条都给出改动位置、关键语义与验收方式；验收全部在真实 `Game` / `Engine`
上跑定点探针（`.cache/phase27/probe_*.py`，共 16 个脚本、188 条断言）。

## P0

### 1. 贾诩【乱武】（`skills/expansions/forest.py`）

`LuanwuFlow` 重写。三个决定全部交给被问的角色：

* `_after_choice`：先问"使用【杀】/ 不使用，失去 1 点体力"；
* 并列最近时开 `SELECT_TARGETS` 让他自己挑打谁（候选先按"能不能真的杀到"
  过滤，`sha_use_options` 判据来自 Card Action Discovery，含【武圣】一类转化）；
* 多张可用【杀】时开 `SELECT_CARDS` 让他挑用哪一张。

出过【杀】之后**不再失血**（旧实现提交动作后没有返回，调用方继续执行
`_punish()`，实测出杀后体力仍被扣 1）。新增规则层原语
`mechanics.sha_use_options`，借刀杀人改为复用它。

验收：`probe_luanwu` 10/10（AI 出杀不失血、无杀者失血、真人有自己的窗口、
并列目标可选、放弃只失血不弃牌）。

### 2. 张昭&张纮【固政】（`skills/expansions/mountain.py`）

`GuzhengFlow` 改为"先返还、再获得"：请求 `min_cards=1` + `cancellable`，
放弃时**一张牌都不移动**；返还的那张必须此刻仍在弃牌堆，否则本次发动整体
作废；单张牌场景只能返还。牌从弃牌堆进出改走 `MoveCardAtom`（原来用裸
`list.remove` / `append`，不发任何事件）。

验收：`probe_guzheng` 10/10（放弃不动牌、两张场景还一拿一、单张只能返还）。

### 3. 神关羽【武神】（`skills/expansions/god.py`、`conversion.py`、发现层、引擎两处入口）

武神改为**锁定替换**：`SkillKind.LOCKED` + `CardConversion(locks_source=True)`。

* `ConversionRegistry.locked_name_for(owner, card)` 是唯一查询口；
* `CardActionDiscovery._normal_option` 对被锁定替换的牌不再生成"按原牌名使用"；
* 引擎侧两个权威入口一起拒绝按原牌名提交：`GameEngine._respond_card` /
  `_group_respond_card`（响应，含无懈链），`UseCardFlow`（出牌）。

因此红桃【桃】【闪】【无中生有】既不能救人、也不能当【闪】打出，只能作为
【杀】参与合法性、响应与距离判断；非红桃牌不受影响。

验收：`probe_wushen` 13/13（含"绕过界面直接提交被引擎拒绝"与"红桃牌仍可
当【杀】正常结算"）。

> 附带影响：武神不再出现在"视为技名单"里（它不再是可点的视为技）。
> `.cache/general_audit/audit_p2_view_as.py` 里针对武神的两条旧断言需要按
> 新语义更新；该脚本在 .cache/ 下，不进 Git。

### 4. 张角【黄天】（`skills/expansions/wind.py`，附带 `core.py`）

改为触发技：**其他群势力角色各自的出牌阶段开始时**，由该角色决定是否把一张
【闪】/【闪电】交给张角（候选与决定权都在交牌者手里，放弃不动任何牌）。
张角不再有主动入口，也不能从别人手里点牌。

同时修掉一个连带缺陷：`_apply_opening_rules` 里身份写回后**重新收敛武将绑定**。
原先 `reset()` 先绑武将、身份随后才写入，主公技（`bind_general` 里按身份判断）
一个都不会绑定——换任何其他方式修黄天都发不出来。

验收：`probe_huangtian` 11/11（窗口问交牌者、候选只有【闪】/【闪电】、放弃不
动牌、非群将不触发、张角无主动入口）。

## P1

### 5. 孙坚/孙策【英魂】、SP 吕布【修罗】（`forest.py`、`sp.py`）

两者都从"出牌阶段点技能名"改成 `PHASE_START(PREPARE)` 的可选流程：窗口在
准备阶段之内开完，结束回合才继续判定 / 摸牌。英魂先选目标（不选 = 不发动，
不写 used），再选"摸 X 弃 1 / 摸 1 弃 X"；修罗的候选只含与判定区延时锦囊
**同花色**的手牌，放弃不弃牌。

验收：`probe_prepare_skills` 14/14；另用 `dbg_sunce` 验证孙策经【魂姿】获得
英魂后，在**后续**准备阶段可以发动。

### 6. 马谡【心战】（`yijiang.py`）

`needs_local_ui` 摘除，改为两个统一请求窗口：①取红桃（候选**只有红桃**，
`min=0`、`max=全部`，放弃不自动获得）；②其余牌按玩家给的顺序放回（
与【观星】同一顺序约定，放弃 = 保持原序）。牌堆顶内容只发给技能拥有者，
公开战报不再写出牌面。

验收：`probe_xinzhan` 11/11。

### 7. 神吕蒙【攻心】（`god.py`）

验收：`probe_gongxin` 9/9（含"公开战报不泄露未展示的牌"）。

### 8. 神吕蒙【涉猎】（`god.py`）

### 9. 神曹操【归心】（`god.py`）

验收：`probe_guixin` 15/15（含 2 点伤害两轮独立询问、两轮翻面抵消）。

### 10. 神吕布【神愤】（`god.py`）

验收：`probe_shenfen` 10/10。

### 11. 司马懿【反馈】、大乔【流离】（`standard/wei.py`、`standard/wu2.py`）

* 反馈：先问是否发动，再由拥有者在来源的**合法区域**里选牌（手牌 = 暗牌随机，
  装备区的牌逐张列出）；拒绝什么都不拿。
* 流离：两段窗口——先选转移目标（取消 = 不弃牌、不改目标），再选要弃的**一张
  合法牌**（手牌或装备牌，取消同样不弃不改）；支付后才改目标。

为支持"重定向阶段可以再问一次"，`UseCardFlow` 的 `redirect` 阶段允许技能写回
新的 `target_redirect` 并保持挂起（通用扩展点，不认识具体技能）。

验收：`probe_fankui_liuli` 17/17。

### 12. 神司马懿【极略】【连破】（`god.py`、`flows/judge.py`）

极略的五个选项按**各自规则时机**开放，每次弃一枚「忍」结算一次：

| 选项 | 时机 | 实现 |
| --- | --- | --- |
| 鬼才 | 判定牌生效前 | `SkillDef.judge_replacement` + 新增的 `on_use` 代价钩子 |
| 放逐 | 你受到伤害后 | `DAMAGE_TARGET_AFTER` 询问 → 选目标 → 摸牌并翻面 |
| 完杀 | 你的出牌阶段开始时 | 询问 → 临时获得【完杀】直到回合结束 |
| 集智 | 你使用非延时锦囊时 | `CARD_USED` 询问 → 摸一张 |
| 制衡 | 出牌阶段 | 主动技入口（`variable_cost` 弃任意张 → 摸等量） |

`JudgeReplacement.on_use` 返回 False 时判定按原牌结算（代价没付、牌也没动）。

连破改为确认窗口：可以拒绝额外回合，标记先清零再问，同一次击杀只问一次。

验收：`probe_jilue_lianpo` 14/14。

### 13. 蔡文姬【悲歌】（`mountain.py`）

### 17. 神关羽【武魂】（`god.py`）

## 附带修复的两处结构性问题（由本次改动暴露）

1. **主公技绑定顺序**（`core.py:_apply_opening_rules`）：身份写回后重新收敛
   武将绑定。以前"先绑武将、后写身份"会让所有主公技（黄天/激将/护驾/救援…）
   根本不绑定。
2. **死亡流程重放**（`flows/death.py`）：DEATH 事件里开的技能窗口（武魂一类）
   之前会把 `DeathFlow` 挂起，恢复时从 `advance` 顶部**重放**整段清理并再发一次
   DEATH 事件（技能触发两次、模式死亡奖惩结算两次）。现在用 `stage` 保证
   清理与宣告只做一次，恢复只走收尾。
